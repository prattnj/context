# context
Stats and analytics from years of SMS receipts

## Setup

### 1. Database (host MySQL, not Docker)
```sh
mysql -u root -p < schema.sql
```
Create a MySQL user with access to the `context` database and put its
credentials in `.env` (copy from `.env.example`).

### 2. Import data
Place exports at `./data/smsdata.xml` and `./data/calldata.xml`, then:
```sh
pip install -r scripts/requirements.txt
python scripts/import.py
```
The script streams the XML (safe for multi-GB files), never modifies the
source files, and is idempotent — re-run it any time to pick up new entries.
MMS attachments are extracted to `./data/media/` as content-addressed files
(`<sha1>.<ext>`) with metadata in the `media` table, so they stay
machine-readable for future tooling.

### 3. Run (production, Docker)
```sh
export PORT_CONTEXT=3100   # or set in .env
docker compose up -d --build
```
The container listens on 3000 internally; `$PORT_CONTEXT` maps to it. Caddy
routes context.noahpratt.com to that port. MySQL is reached on the host via
`host.docker.internal`.

### Local development
```sh
cd server && npm install && npm run dev      # API on :3000
cd frontend && npm install && npm run dev    # Vite dev server, proxies /api
```

### Environment variables
See `.env.example`: DB connection, `APP_PASSWORD` (the site password),
`SESSION_SECRET` (cookie signing), `GEMINI_API_KEY` / `GEMINI_MODEL`
(month summaries), `PORT_CONTEXT`.
